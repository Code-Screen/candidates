# Record video

### Recording video using the Desktop App
Click [`here`](https://support.loom.com/hc/en-us/articles/360002207917-Getting-started-with-the-Desktop-App) for instructions on recording a video with the `Desktop App`.

### Recording video using the Chrome Extension
Click [`here`](https://support.loom.com/hc/en-us/articles/360002187698) for instructions on recording a video with the `Chrome Extension`.

<br>

**Note** - Please make sure to use the `Screen+Cam` option so both you and your screen are visible in the video.

Once you have finished recording a video, you are ready to <a href="#submit">submit your solution</a>.
