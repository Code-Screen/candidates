# Prerequisites

* <a href="https://www.github.com" target="_blank">GitHub</a> - `GitHub` is a core part of the CodeScreen workflow. If you do not already have a `GitHub` account, you can sign up <a href="https://www.github.com" target="_blank">here</a> for free.

* <a href="https://git-scm.com/" target="_blank">Git</a> - In order to push your changes to `GitHub`, you will first need to 
<a href="https://git-scm.com/book/en/v2/Getting-Started-Installing-Git" target="_blank"> install Git</a> on your computer.
